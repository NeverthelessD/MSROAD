MSROAD Windows 사용 가이드

악보 파일 이름의 코드를 읽어서 A부터 G까지 일곱 ROAD로 나누고, 바로 크게 봐요

🪟 Windows 10 · 11 (64비트) 🧭 설치 없이 MSROAD.exe 하나 🖼 JPG · PNG · GIF · WEBP · PDF 🔎 이름 · 초성 · 코드 검색 🖨 편집 · 인쇄 · PDF 🔄 자동 업데이트 🌓 라이트 · 다크

처음 한 번만 1분이면 끝나요

1

압축 풀고 옮기기

MSROAD-Windows.zip을 오른쪽 클릭 → 모두 압축 풀기. 나온 MSROAD 폴더를 문서 같은 편한 곳에 두고 MSROAD.exe를 두 번 눌러요.

2

보안 허용

파란 “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행. 처음 한 번만 물어봐요.

3

악보 폴더 고르기

악보 폴더 고르기를 누르면 앱 안에 폴더 목록이 떠요. 바탕 화면 · 문서 · 드라이브에서 찾아 들어가 이 폴더의 악보 보기. 하위 폴더까지 함께 읽어요.

4

다음부터는 바로

앱을 켜면 마지막에 본 폴더가 그대로 열려요. 위쪽 📁 폴더 이름을 누르면 바꿀 수 있어요.

위쪽 Ab A G 같은 키 버튼을 눌러도 바로 바뀌어요. 확대했을 땐 끌어서 움직이고, 두 번 누르면 크게 · 원래대로.

🖨 편집 · 인쇄 위쪽 편집 · 인쇄를 누르면 열려요 · 원본 악보 파일은 그대로예요

1

틀 고르기

A4 · A3, 세로 · 가로, 한 페이지에 1곡 · 2곡 · 3곡 나란히, 4곡(2×2) 또는 자유 배치. A3 가로에 2곡이면 곡마다 A4 크기 그대로예요.

2

악보 넣기

왼쪽 목록에서 끌어서 칸에 놓거나 두 번 눌러요. 여러 장 악보는 다음 칸에 이어서 들어가고, 칸끼리 끌어 자리를 바꿔요.

3

다듬기

자르기(빈 여백 자동) · 확대 · 축소는 칸 안에서, 가로 · 세로 따로도 돼요(가장자리 끌기). 다른 키로 바꾸기 · Ctrl+Z로 되돌리기.

4

인쇄 · PDF

미리보기로 확인하고 인쇄(Ctrl+P) — PDF 창이 열리면 그 창에서 한 번 더 Ctrl+P — 또는 PDF로 저장. 배치는 세트로 자동 저장돼 다음에 다시 열어요.

✍️ 글자 넣기 — 페이지 위 · 아래 여백을 누르면 ‘20261003 금요기도회’ 같은 여백 글자를 모든 페이지 또는 한 페이지에만 넣어요(+ 날짜 · + 쪽 번호). 위쪽 글자 상자로는 페이지 아무 곳에나 메모를 놓고 크기 · 색 · 흰 바탕을 골라요.

그 밖에

오른쪽 클릭미리보기 · 코드 바꾸기 · 탐색기에서 보기 · 기본 앱으로 열기
새 악보앱을 켤 때 · 창으로 돌아올 때 폴더를 알아서 다시 읽어요. 위쪽 ⟳ 새로고침(Ctrl+R)으로 바로 읽을 수도 있어요. 새로 들어온 악보는 NEW에 모이고 ‘새 악보’ 표시가 붙어요
보기이름순 · 최근 바뀐 순, 악보 크기 작게 · 보통 · 크게
화면 모드오른쪽 위에서 시스템 설정 따르기(기본) · 라이트 · 다크
업데이트새 버전이 나오면 앱이 알아서 받아요. 오른쪽 위 버전 표시를 누르면 지금 버전 확인 · 업데이트 확인 · 이전 버전으로 되돌리기

⚠️ 알아두면 좋은 점

🛡️
악보 파일은 옮기거나 지우지 않아요. 그 자리에서 읽기만 해요.
✏️
코드 정하기는 실제 파일 이름을 바꿔요. 바꾼 직후 알림의 되돌리기로 원래대로 돌릴 수 있어요.
☁️
OneDrive · 공유 폴더라면 바뀐 이름이 다른 기기와 사람에게도 그대로 보여요.
🔤
코드는 대문자 A~G로. 소문자(ab.jpg)나 영어 제목 바로 뒤에 붙인 코드(HolyD.jpg)는 못 읽어요 → Holy_D.jpg
📷
HEIC(아이폰 사진)는 Windows 버전에서 읽지 않아요. 아이폰에서 JPG로 내보내거나, 설정 → 카메라 → 포맷 → 높은 호환성으로 찍어요.
⏻
끄려면 오른쪽 위 ⏻를 눌러요. 창만 닫았다면 MSROAD.exe를 다시 누르면 그대로 열리고, 오래 안 쓰면 알아서 꺼져요.
⏳
PDF 악보는 처음 볼 때 조금 걸려요. 한 번 만든 미리보기는 저장해 둬서 다음엔 빨라요.
🗑️
